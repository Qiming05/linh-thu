# Linh Thú Hán Tự

RPG pixel học tiếng Trung cho người Việt: mỗi bài học là một vùng đất mới, đánh linh thú bằng cách trả lời từ vựng, bắt linh thú bằng Linh Châu.

- Chơi: mở `index.html` qua một web server (ví dụ `python -m http.server`), hoặc bản trên GitHub Pages.
- Cài như app trên điện thoại: mở trang trong Chrome/Safari → "Thêm vào màn hình chính".
- Chuyển tiến trình giữa các máy: nút **💾 Tiến trình** trong game.
- Tài liệu cho người phát triển: [HANDOVER-GAME.md](HANDOVER-GAME.md).

Hình ảnh: Kenney (kenney.nl) và isaiah658 (OpenGameArt), giấy phép CC0.
